# 本町中華食堂（仮）QR注文・会計システム導入设计

## 目标

把现有静态 demo 改造成船橋市本町エリア中華料理店的首版客户演示系统：客人在桌面 QR 页面点菜，厨房查看订单，收银按桌结账，后台可调整菜单、售罄和桌台。

## 已确认资料

- 对外演示名称：本町中華食堂（仮）
- 地址显示：船橋市本町エリア
- 电话显示：店頭確認
- 公开平台显示约 60 席，可宴会，主打本格中華、食べ飲み放題、晩酌セット、拉麺、定食。
- Google 图片显示：食べ飲み放題 3500 円、4 名様から、最大 70 名様まで；晩酌セット 680 円；拉麺 690-790 円；店外白板有多种定食 680-780 円。

## 范围

首版先做可当场演示和可带去客户沟通的系统，不处理线上支付、真实打印机、后端数据库、员工账号和库存同步。价格和菜单基于公开资料与照片整理，交付客户前需要由店家确认。

## 功能设计

- 点菜页：默认桌号 3，展示仮名品牌、地址区域、营业/支付提醒、分类菜单、购物车、备注、下单。
- 厨房页：按订单显示桌号、时间、菜品、备注，支持新规、調理中、完成。
- 会计页：按桌汇总未结账订单，默认现金结账，保留卡/QR 为店家确认后可开关的选项说明。
- 后台页：维护菜单、售罄、推荐、桌台状态，重置演示数据。
- 多语言：日文为主，中文给店员/华语顾客，英文给游客。

## 菜单策略

分类采用：おすすめ、定食、晩酌セット、食べ飲み放題、麺・拉麺、飯類、点心、前菜・冷菜、肉料理、海鮮・野菜、揚げ物、ドリンク。首版录入 45 个左右高频菜品，覆盖照片与公开菜单；看不清的图片菜名不强行录入。

## 客户导入任务

1. 带系统去店里确认菜单、价格、席位编号和支付方式。
2. 用店铺手机扫桌牌 QR，确认点菜流程。
3. 在厨房或收银台电脑打开厨房页和会计页。
4. 让店员试用售罄、改单价、重置演示数据。
5. 收集反馈后再决定是否做后端、打印、员工权限和正式部署。
