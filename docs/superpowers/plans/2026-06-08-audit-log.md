# Audit Log Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a local operations audit log and admin display for key restaurant actions.

**Architecture:** Extend `assets/izakaya-core.js` with normalized `auditEvents`, a `recordAuditEvent` helper, and `auditEvents()` query. Existing business functions record events at the same point they save store changes. `assets/izakaya-ui.js` renders recent events on the admin page.

**Tech Stack:** Static HTML, vanilla JavaScript, localStorage-backed core store, Node assert tests.
