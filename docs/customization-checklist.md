# 客户定制清单

从 demo 复制成客户正式系统时，按这份清单逐项确认。

## 品牌信息

- 店铺/公司名称
- Logo
- 主色
- 电话
- 邮箱
- LINE / WeChat / WhatsApp 等联系方式
- 地址
- 营业时间
- 官网或社交媒体链接

## 业务配置

- 是否开启堂食
- 是否开启外卖
- 是否开启到店自取
- 是否需要预约
- 是否需要会员
- 是否需要优惠券
- 是否需要多语言
- 是否需要税率、服务费、配送费配置

## 商品或服务数据

居酒屋：

- 分类
- 菜单
- 价格
- 图片
- 推荐品
- 售罄状态
- 桌台数量

二手车：

- 车辆库存
- 车况字段
- 价格字段
- 询盘流程
- 商谈记录

再生资源：

- 回收品类
- 重量记录
- 回收预约
- 路线安排
- 结算方式

房产中介：

- 房源字段
- 看房预约
- 客户跟进
- 合同进度
- 担当者管理

## 设备和现场

- 顾客手机
- 店员手机
- 平板
- 厨房屏幕
- 会计电脑
- 打印机
- 钱箱
- 网络环境

## 支付和数据

- 现金
- PayPay
- LINE Pay
- WeChat Pay
- Alipay
- 信用卡
- 银行转账
- 是否接入真实支付 API
- 是否需要云端数据库
- 是否需要备份

## 上线确认

- 客户确认画面
- 客户确认流程
- 客户确认价格
- 客户确认上线日期
- 客户确认维护方式
