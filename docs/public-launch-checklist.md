# 公開前チェックリスト

このチェックリストは、居楽テックの会社サイトと居酒屋 demo を GitHub Pages で公開する前に確認する項目です。

## GitHub Pages

- `main` ブランチの最新コミットが GitHub に push されている。
- GitHub Pages の公開 URL が `https://xuebin007.github.io/irakutech/` で開ける。
- `robots.txt` と `sitemap.xml` が公開 URL で読める。
- `404.html` が存在し、迷ったユーザーをデモ一覧に戻せる。

## デモ版の注意

- 顧客に「現在は静的 demo で、データはブラウザ内に保存される」と説明する。
- 本番導入前に、ログイン、権限、クラウド DB、バックアップ、印刷、決済連携が必要なことを説明する。
- 商談前に后台の「デモデータをリセット」を実行する。

## 動作確認

- 会社サイト `/` から居酒屋 demo へ遷移できる。
- `/order/?table=3` で点菜、追加注文、未会計合計が確認できる。
- `/takeout/` で外卖・自取注文が作れる。
- `/kitchen/` で新規、調理中、完成へ移動できる。
- `/checkout/` でテーブル会計、店外注文会計、日締め、テーブル操作が確認できる。
- `/admin/` でメニュー、在庫、スタッフ、シフト、顧客、QR 管理が確認できる。
